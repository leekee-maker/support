WenJian Privacy Policy / 文涧隐私政策

Last updated: August 8, 2026 / 更新日期：2026 年 8 月 8 日

1. Overview / 概述

WenJian is a macOS Markdown note-taking and writing app. It is designed to work with local files first and to avoid unnecessary account systems or tracking.

文涧是一款 macOS Markdown 笔记与写作工具。我们将其设计为本地文件优先，并避免不必要的账号系统或追踪。

2. Data Stored on Your Device / 本机存储的数据

WenJian reads and writes Markdown files in the folder you choose. Your notes, titles, folders, and Markdown content are stored locally or in the storage provider you select.

文涧读取和写入你选择的 Markdown 文件夹。你的笔记、标题、文件夹和 Markdown 内容保存在本机，或保存在你主动选择的云盘同步目录中。

3. Cloud Sync / 云同步

WenJian does not provide its own cloud account or server sync. If you use iCloud Drive, Nutstore, Dropbox, or another sync folder, synchronization is handled by that provider under its own terms and privacy policy.

文涧不提供自有云账号或服务器同步。如果你将笔记放在 iCloud Drive、坚果云、Dropbox 或其他同步文件夹中，同步由对应服务商按其条款和隐私政策处理。

4. Data Collection / 数据收集

WenJian does not collect your note content, does not sell personal data, and does not track users across apps or websites for advertising.

文涧不收集你的笔记内容，不出售个人数据，也不会为了广告目的跨 App 或跨网站追踪用户。

5. Permissions / 权限

The app may request file or folder access so you can open and save Markdown files. This permission is used only for editing and file management features you request.

App 可能请求文件或文件夹访问权限，用于打开和保存 Markdown 文件。该权限仅用于你主动使用的编辑和文件管理功能。

6. Data Deletion / 数据删除

You can delete notes from the folders you manage. Removing the app from your Mac does not automatically delete Markdown files stored outside the app container.

你可以在自己管理的文件夹中删除笔记。卸载 App 不会自动删除保存在 App 容器之外的 Markdown 文件。

如果你对隐私政策有疑问或需要支持，请发送邮件至 1515149334@qq.com。
