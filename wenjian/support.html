WenJian 技术支持

WenJian 是一款 macOS Markdown 笔记与写作工具，主打本地优先、轻量整理和专注编辑。

常见问题

  • 如果首次打开没有内容，请在偏好设置中选择一个可读写的 Markdown 文件夹。
  • 如果云盘同步不及时，请确认 iCloud Drive、Nutstore、Dropbox 等客户端已完成本地同步。
  • 如果预览内容未更新，请切换笔记或重新打开 App 后再试。
  • 如果快捷键或格式工具栏无响应，请确认当前焦点位于编辑器中。

数据与隐私

WenJian 优先读写你选择的本地 Markdown 文件夹，不要求注册账号。完整说明见 隐私政策。
