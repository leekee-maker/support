WenJian Support / 文涧技术支持

WenJian is a local-first Markdown note-taking and writing app for macOS. 文涧是一款 macOS Markdown 笔记与写作工具，主打本地优先、轻量整理和专注编辑。

FAQ / 常见问题

  • If the app opens with no notes, choose a readable and writable Markdown folder in Preferences. 如果首次打开没有内容，请在偏好设置中选择一个可读写的 Markdown 文件夹。
  • If cloud sync is delayed, check whether iCloud Drive, Nutstore, Dropbox, or your selected sync client has finished syncing locally. 如果云盘同步不及时，请确认对应云盘客户端已完成本地同步。
  • If preview content does not update, switch notes or reopen the app and try again. 如果预览内容未更新，请切换笔记或重新打开 App 后再试。
  • If shortcuts or toolbar actions do not respond, make sure the editor is focused. 如果快捷键或格式工具栏无响应，请确认当前焦点位于编辑器中。

Privacy / 数据与隐私

WenJian primarily reads and writes local Markdown files and does not require user registration. 文涧优先读写你选择的本地 Markdown 文件夹，不要求注册账号。See Privacy Policy / 隐私政策.
